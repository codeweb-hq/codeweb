The seat definition

What counts as an active author

One definition, stated once, computed the same way everywhere.

Who

A person who authored a commit on the default branch of a repository where the gate is enabled. Reviewers, readers, and bots are not seats.

When

In the trailing 90 days. Stop committing and the seat drops off on its own; nobody has to file a ticket to remove a leaver.

Counted once

Distinct authors, deduplicated by commit email and account login together. The same human committing from a laptop and a CI box is one seat.

The equivalent hand check on any repository: git log --since=90.days on the default branch, distinct authors. Nothing is inferred, and nothing is estimated.

Flat, not metered

The gate costs us nothing per run, so it costs you nothing per run

codeweb's verdict is a deterministic graph diff. No model is called, so a busy week is not an expensive week.

Usage-metered pricing, the category norm

Review tools built on model calls carry per-use cost, so their pricing tends to follow it: credits, per-review quotas, overage on top of the seat price.

The budgeting cost is real too — someone has to watch the meter and decide which pull requests deserve a review.

What flat-unlimited means here

One price per active author. Every repository, every pull request, every gate run, every dashboard query — no credits, no quota, no overage line.

Gate the noisy refactor branch as readily as the release branch. The bill is the same either way.

For category context: the competitive scan committed in this repository (reports/COMPETITIVE.md) recorded commercial code-analysis gates priced at €18–27 per active author per month. We deliberately price under the category we are entering; no claim here describes any specific competitor.
