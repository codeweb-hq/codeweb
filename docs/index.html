FAQ

Direct answers to the questions people actually ask

The same answers your agents get — short, measured, and sourced. The numbers trace to the evidence ledger.

What is codeweb?

codeweb is an MCP server and Claude Code plugin that reads your code and maps it: every function, and every call between them (~3s for 3,000 symbols). Static analysis, no LLM — the same code always produces the same map. Coding agents query the map over 28 deterministic MCP tools; you get a self-contained interactive map. Free & MIT.

What breaks if I change this function?

The question codeweb exists to answer: codeweb_impact returns the blast radius — every function transitively affected by a change — before the edit is written. Measured on 30 vite symbols, one ~1KB codeweb call replaced a ~130KB grep loop: 126× cheaper.

Why do coding agents need a call graph instead of grep?

grep misses more than half of a function's real callers, and agents break the code they can't see. In measured tests, agents found 74% of a function's real callers with the map and 44% with grep, at the same context cost (v0.9.0 pilot, better in all 5 runs).

Does codeweb send my code anywhere or execute it?

No. codeweb runs entirely on your machine: no accounts, no telemetry, zero runtime dependencies — and it reads code, never executes it. No LLM in the analysis loop, so the same repo always yields the same graph.

Which languages does codeweb support?

13 languages natively — JavaScript, TypeScript, Python, Rust, Go, Java, C#, Ruby, PHP, Kotlin, Swift, C, and C++ — with an agent fallback for everything else.

How do I install codeweb?

Three ways: the Claude Code plugin (/plugin marketplace add GhostlyGawd/codeweb, then /plugin install codeweb), a one-shot map of the current repo (npx -y @ghostlygawd/codeweb .), or the MCP server for any MCP client (claude mcp add codeweb -- npx -y -p @ghostlygawd/codeweb codeweb-mcp).
